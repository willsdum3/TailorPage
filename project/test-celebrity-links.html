🔗 Celebrity Book Links Test - Enhanced

Testing if Amazon links actually go to the right books (not just generic pages)

📋 How to Test:

  1. Click "Test Link" for each book
  2. Check if the page shows the actual book (title, author, book details)
  3. Mark as:
    • ✓ Working - Goes to the right book page
    • ⚠️ Redirect - Goes to Amazon but wrong/generic page
    • ✗ Broken - 404 error or completely wrong page
